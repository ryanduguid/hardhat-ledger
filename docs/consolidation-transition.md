# Consolidation transition

Australian Accounting Skills v0.2.0 is the maintained home for these ten
contracting skills. The replacement is publicly verified through Claude Code,
Codex and Skills CLI installation routes. Its release records the transfer
source, exact inventory, validation cards and safety-boundary review.

## Compatibility contract

The transfer preserves all ten skill names, their front matter, current-source
checks, standalone safety boundary and human-review gates. Hardhat Ledger v0.1.6
keeps the former plugin and marketplace identifiers for rollback without
changing skill content.

The two packs expose duplicate skill names. Remove or disable Hardhat Ledger
before enabling Australian Accounting Skills. A simultaneous installation can
select the wrong copy and hide which release supplied a workflow.

## Completed gates

1. Hardhat Ledger v0.1.5 passed its manifest, Claude, Codex, Skills CLI, unit,
   fabricated-validation and standalone-safety checks.
2. Australian Accounting Skills copied the ten directories from retained
   transfer commit `eb3b8a6ba47dfcdc05cea434f2f6a7dba82f96ef` and published v0.2.0.
3. Clean installations verified the v0.2.0 Claude marketplace, Codex plugin and
   `skills@1.5.22` routes, including all nineteen destination skills.
4. Hardhat Ledger v0.1.6 marks this source deprecated and directs new installs
   to the verified replacement.

## Observation and archival

Keep this repository active for fourteen calendar days after v0.1.6 becomes
public. Recheck all three replacement install routes and the v0.1.5 rollback at
the end of that period. Archive only after those checks pass. Preserve every
tag, release, asset and the `transfer-source/2026-08-15` retention tag.

## Rollback

Keep Hardhat Ledger unarchived and restore the immutable
[v0.1.5 release](https://github.com/ryanduguid/hardhat-ledger/releases/tag/v0.1.5)
if destination discovery, behaviour or documentation regresses. Disable the
destination pack before restoring the old plugin so duplicate names cannot
mask the rollback.
